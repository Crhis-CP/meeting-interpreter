新手上手

先选你的情况，照着做三四步就能用。对方什么都不用装。

💻 线上开会（推荐）用浏览器开 Teams / Zoom / 腾讯会议 / 飞书 🖥 线上开会（客户端）用会议软件的电脑 App 🤝 面对面一对一拜访客户、当面聊 👥 多人现场开会大家用手机扫码听同传 🔑 第一次：拿 Key两分钟，新用户有免费额度 ❓ 常见问题听不到、没反应怎么办

🔑 第一次：拿一个 Key

Key 就像一张“上网卡”，用来连接语音识别和翻译服务。费用由你自己的账号承担，本软件不收任何钱。

推荐：阿里云百炼（最准，新用户有免费额度）

  1. 打开 阿里云百炼，用手机号或支付宝登录，按提示完成实名认证。
  2. 点 “创建 API Key”，复制那一串以 sk- 开头的字符。
  3. 粘贴到软件里（软件里每个要填 Key 的地方都有“去获取 ↗”按钮，点了直接跳到这个页面）。

用完免费额度后按用量计费，一小时会议大约 2–4 元。可以在百炼控制台设置消费提醒。Key 只保存在你自己的设备上，别人看不到。

完全免费：智谱 Key + 桌面版

  1. 打开 智谱开放平台，手机号注册登录。
  2. 点 “添加新的 API Key”，复制粘贴到软件里，方案选 “免费”。
  3. 免费方案的识别在你电脑上离线完成，第一次会自动下载约 500MB 的模型。

💻 线上开会（推荐：浏览器 + 插件）

你说中文，对方在会议里听到西语 / 英语；对方说话，你屏幕上出现中文字幕。不用装虚拟声卡。

  1. 用电脑上的 Chrome 或 Edge 浏览器，在 下载页 下载 Chrome 插件，双击解压。
  2. 浏览器地址栏输入 chrome://extensions（Edge 输入 edge://extensions），打开右上角 “开发者模式”，点 “加载已解压的扩展程序”，选刚才解压出来的文件夹。点拼图图标 🧩 把“会议同传”钉在工具栏上。
  3. 打开会议链接，选 “在浏览器中加入 / 使用网页版”，入会。
  4. 点工具栏上的插件图标，选对方说的语言和方案，第一次会提示你粘贴 Key，点 “开始同传”。

建议戴耳机。插件装好前就已经在会议里的话，刷新页面重新入会。结束后点插件里的“会议记录”可以下载双语记录、生成纪要。

🖥 线上开会（会议软件的电脑客户端）

需要电脑版的“会议同传助手”，外加一个虚拟麦克风（软件里一键安装）。

  1. 在 下载页 下载电脑版并安装。Mac 第一次打开如果提示“无法验证开发者”：系统设置 › 隐私与安全性 › “仍要打开”。Windows 提示时点“更多信息” › “仍要运行”。
  2. 打开软件，按引导：选对方语言 → 选方案、粘贴 Key → 点 “一键安装虚拟麦克风”（Mac 会让你输入一次电脑密码）。
  3. 在会议软件（Teams / 飞书 / 腾讯会议 / Zoom）的“音频设置”里，把 麦克风 选成 BlackHole 2ch（Mac）或 CABLE Output（Windows），扬声器不用改。
  4. 在会议同传助手里点 “开始同传”，戴上耳机开会。

对方说话时你会在耳机里听到中文译音，同时有悬浮字幕；只想看字幕可以关掉“播放中文译音”。

🤝 面对面一对一

安卓手机：一部手机放中间

  1. 用安卓手机打开 下载页，点 “下载安卓版”，安装（提示“未知来源”时点允许）。
  2. 打开 App，点右上角 ⚙️，粘贴百炼 Key（有“去获取 Key”按钮）。
  3. 把手机放在你们中间，点 “开始对话”，谁说都行：说中文它就念外语，说外语它就念中文。周围吵就切到 “按住说话”。

苹果手机

苹果手机不能从网站安装 App，请用电脑开“现场房间”，手机扫码使用（见下一节），两个人各用自己的手机也可以。

👥 多人现场开会（现场房间）

一台电脑开房间，每个人用自己的手机扫码，不用装任何东西，苹果安卓都行。

  1. 电脑上打开会议同传助手，点左边 “现场房间” › “开启房间”。大家在同一个 Wi-Fi 就直接扫屏幕上的二维码；不在一起的人，打开 “公网链接” 再扫。
  2. 每个人用手机相机扫码，填名字，选自己说的语言（中文 / Español / English），点“加入”，戴上耳机。
  3. 说话时 按住手机上的大按钮，松开就翻译。其他语言的人会在耳机里听到译音，同时看到字幕。

一个人说完再到下一个人，效果最好。每个房间都有独立的随机密码，不同电脑开的房间互不干扰；手机拿不到你的 Key。

❓ 常见问题

对方听不到我的翻译

  1. 插件：确认点了“开始同传”，并且是在装插件之后才入的会（不然刷新页面重新入会）。
  2. 客户端：确认会议软件里的麦克风选的是 BlackHole 2ch / CABLE Output，并且没有在会议里静音。

没反应 / 提示 Key 不对

  1. 在设置里点 “测试一下”，按提示改。Key 前后不要多空格；百炼 Key 的地域（中国 / 国际）要和你注册的一致。

专有名词翻错了

  1. 在 术语表 里加上：中文、外文的固定叫法，以及常被听错的写法（别名）。

会不会把我的原声传过去？

不会。同传时会议里只有翻译后的声音，你的原声不会传过去。想自己直接说外语时，打开“原声直通”。
