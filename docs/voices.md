# 自然人声：怎么选的、怎么测的

免费方案的语音是本机生成的自然人声（Kokoro-82M，Apache-2.0，sherpa-onnx 的 ONNX 版本）。一个模型（约 370 MB）里有中文、西语、英语的声音，每种语言给用户一个女声、一个男声。

## 选定的声音

| 语言 | 女声 | 男声 | 语速 | 怎么定的 |
|---|---|---|---|---|
| 中文 | 晓晓（sid 47） | 云希（sid 50） | 女 1.27×、男 1.10× | 三轮试听；第三轮把所有中文声音调到同样的每秒约 5.8 个字后选定 |
| 西语 | Dora（sid 28） | Alex（sid 29） | 1.1× | 两轮试听，1.1× 选定 |
| 英语 | Heart（sid 3） | Michael（sid 16） | 1.0× | 暂定，待试听（1.0× 已是每分钟约 200–215 个词，日常说话约 150–190） |

清单在 `src/main/providers/neural-tts/models.ts`，换声音只改编号和语速。

### 为什么每个声音的语速不一样

不同声音天生快慢不同。实测 1.0× 时（4 句会议常用句，去掉首尾静音）：

| 声音 | 1.0× 每秒字数 |
|---|---|
| 云希 | 5.44 |
| 晓晓 | 4.89 |
| v1.1 女声 C / D | 4.46 / 3.95 |
| v1.1 男声 C / D | 4.22 / 4.16 |

日常说话每秒 5–6 个字，第二轮的 v1.1 声音只有约 4 个字，所以听起来慢。现在每个中文声音单独调到每秒约 5.8 个字。

### 起伏

按音高范围测（半音），合成声音并不比真人平：真人中文 4.68、西语 5.44；云希 5.03、晓晓 6.75、Dora 5.56、Alex 4.32。听起来“平”主要是节奏均匀、没有重音。目前的改进方式：

- 按整句合成，不在逗号处断开重来；
- 每句单独生成，保留句子的语调；
- 语速调到正常说话的快慢。

## 占用

- **内存：** 模型加载后，合成进程约 650 MB，说话时约 720 MB。加上本机识别约 0.9 GB、本机 AI 翻译约 1.3 GB，免费方案开会时合计约 3 GB，8 GB 内存的电脑够用。
- **空闲释放：** 不开会、10 分钟没说话，合成进程自动退出，释放这部分内存。
- **模型精度：** 用全精度模型。int8 版虽然小一些，但在普通电脑上慢约 3 倍。

## 怎么检查读得对不对

把合成的声音交给软件自己的识别模型听写回来，再和原文比（`tests/main/neural-tts.int.test.ts`）。CI 在 Mac 和 Windows 上用真模型跑，要求：

- 每个声音生成速度都比说话快（实测普通 4 核电脑约 3–4 倍）；
- 第一句约 0.3–0.8 秒出声；
- 听写回来的错误率低于 10%。

识别器会把“一千”“百分之五”写成“1000”“5%”，比较前统一成文字。

第三轮（每秒约 5.8 字，6 句）听写错误率：云希 0%、晓晓 2.7%、v1.1 女声 C 0%、男声 D 0%、男声 C 0.9%、女声 D 3.5%。

晓晓有一个“第一批”被听成“一批”的情况：音频前面留半秒静音、直接交给识别模型时，每句都对；经过语音检测（VAD）时，句首的“第”有时被切掉。这是识别一侧的问题，记入审计台账，在第 5 步口音和识别评估里一起测（真人说话的轻声起音也可能受影响）。

## 西语怎么读

sherpa-onnx 2.x 去掉了 espeak-ng（GPL），西语由我们自己转成音标再交给模型：

1. **读法**（`src/core/speech-text/es-read.ts`）：
   - 数字、金额、百分比、时间、日期变成西语的说法；
   - 型号、编号照写法逐个读；
   - 缩写按西语字母读。
2. **发音**（`src/core/speech-text/es-phonemes.ts`）：
   - 拉美口音：c/z 读 s，ll/y 读 ʝ；
   - 重音按书写规则；
   - b/d/g 在元音间变软；
   - n 在 b/p/m 前读 m，在 k/g/x 前读 ŋ。
3. **分句**（`src/core/speech-text/kokoro-input.ts`）：一句一个输入，太长的按逗号切开（模型一次最多约 500 个音标）。

中文和英语直接给文字，由模型自带的词表和数字规则来读。

## 没下载好、出错时

用电脑自带的声音顶上（`FallbackTts`）：

- 没下载好时，第一句就换成系统声音，这场会议不再试。
- 合成进程意外退出时，同样换成系统声音；下一场会议重新启动。
- 电脑太慢时：连续 3 句（每句 1 秒以上）生成时间都超过说话时长的 1.1 倍，这场会议就改用系统声音，并提示一次，免得译音越拖越晚。中间有一句跟上了就重新计数，所以偶尔一忙不算。下一场会议再试。
- 试听只用自然人声本身，没下载好就直接说明，不拿系统声音冒充。
