### 下载哪个文件？

| 电脑 | 文件 |
|---|---|
| Mac（Apple 芯片：M1/M2/M3/M4…） | `MeetingInterpreter-*-mac-arm64.dmg` |
| Mac（Intel 芯片） | `MeetingInterpreter-*-mac-x64.dmg` |
| Windows 10 / 11 | `MeetingInterpreter-*-windows-x64-setup.exe` |
| Linux | `MeetingInterpreter-*-linux-x86_64.AppImage` |

**Mac 第一次打开**：打开后提示“无法验证开发者”时，到 系统设置 › 隐私与安全性 点“仍要打开”；如果提示“已损坏”，在终端运行 `xattr -cr /Applications/MeetingInterpreter.app`。

**Windows**：SmartScreen 提示时点“更多信息” › “仍要运行”。

使用说明见 [README](https://github.com/Crhis-CP/meeting-interpreter#readme)。可用 `SHA256SUMS.txt` 校验下载文件。
