# 中文口音：特征、地区和软件怎么用

会议同传要听懂“你”。很多人的普通话带家乡口音，而且常常是几种口音混在一起（老家一种、读书工作的地方又一种）。所以软件**不让用户选地区**：所有已知的口音特征都内置，对每个人都考虑；你实际有哪些特征，从你的校准、改正和会后学习里自动算出来。

## 口音特征

“特征”指普通话里两个音被说成同一个，识别器就把字听成另一个字。下表是汉语方言学和普通话教学（“方言辨正”）里最常见的几类。地区只写最典型的，实际分布更广、也因人而异。

| 特征 | 例子（说的 → 被听成） | 常见地区 |
|---|---|---|
| n / l 不分 | 南 nan → 兰 lan，牛 niu → 刘 liu | 西南官话（川渝、云贵）、湘、赣、江淮、闽、粤部分 |
| f / hu 不分 | 花 hua → 发 fa，飞 fei → 灰 hui，分 fen → 昏 hun | 闽、客家、湘、赣、西南部分 |
| f / h 不分 | 飞 fei → 黑 hei | 闽、客家部分 |
| zh ch sh / z c s 不分 | 知 zhi → 资 zi，柴 chai → 才 cai，是 shi → 四 si | 吴、闽、粤、客家、西南、东北部分、江淮 |
| r / l 不分 | 日 ri → 力 li，热 re → 乐 le | 西南、江淮、闽、东北部分 |
| r 读成 y | 人 ren → 银 yin，肉 rou → 又 you，软 ruan → 远 yuan | 东北、胶辽（山东半岛） |
| in / ing 不分 | 新 xin ↔ 星 xing | 西南、江淮、吴、湘、赣、西北、东北部分 |
| en / eng 不分 | 分 fen ↔ 风 feng | 西南、江淮、吴、湘、赣、西北 |
| an / ang 不分 | 班 ban ↔ 帮 bang | 吴、湘、江淮部分、西北部分 |
| ian / iang、uan / uang | 建 jian ↔ 讲 jiang，关 guan ↔ 光 guang | 同上（an / ang 的延伸） |
| eng / ong 不分 | 风 feng → 轰 hong，朋 peng → 蓬 pong | 西南、湘、闽部分 |
| un / en 不分 | 存 cun → 岑 cen，顿 dun → 扽 den | 粤、闽、西南部分 |
| e / uo 不分 | 哥 ge → 锅 guo，河 he → 活 huo | 西南、湘、西北部分 |
| ü 读成 i | 去 qu → 气 qi，女 nü → 你 ni，鱼 yu → 姨 yi | 粤、客家、闽、西南部分 |
| j q x 读成 z c s（尖音） | 西 xi → 思 si，鸡 ji → 资 zi，小 xiao → 扫 sao | 闽、粤、吴部分，河南、山东部分 |

**声调：** 很多口音也体现在声调上，但识别器输出的是汉字。声调读偏通常让识别器在同音字之间选错（买 / 卖），这一类已经由“改正学习”和术语表覆盖，不单独作为特征。

## 软件怎么用这些特征

代码在 `src/core/profile/accents.ts`。

1. **识别。** 比较“应该是什么”和“识别成什么”时：
   - 先把数字统一成读法：识别器会把“四十万”写成“40万”，这不算错。
   - 多音字按整句读（“银行”的“行”读 hang，“步行”的“行”读 xing）。
   - 逐字对齐，看每个读错的字是不是某个特征造成的。f / hu 这类声母和韵母同时变的（方 fang → 荒 huang），旧版本识别不出来，现在可以。
2. **记录你的特征。** 三个来源，都会计入你的口音档案：
   - **口音校准：** 16 句短句，每个特征的每个方向至少出现 3 次（有测试保证），句子里有人名和数字。结果按方向显示，例如“n 听成 l：5 次里 4 次”。读完后，可以只针对出现过的特征再测一轮（每个特征 2 句）。
   - **你改正的句子：** 改正里如果有字是因为某个特征听错的，就记一次。
   - **会后自动学习：** 同上，大模型找出来的听错也会记。

   所以不做校准也会越用越准。校准只是让第一天就准。
3. **反证会让特征淡化。** 某个特征在一次校准里测了 3 次以上、一次都没听错，它的计数减半。一次偶然的误听，或者很久以前的结果，不会永远放宽匹配。
4. **只放开你确认过的特征。** 术语的“按读音纠正”默认只认最常见的几类（n / l、f / h、平翘舌、前后鼻音），新加的特征（f / hu、r / y、ü / i、尖音等）只有在你身上出现过至少 2 次才参与匹配。从来没在你身上出现过的特征，不会改你的字。
5. **不误改。** 一套 40 句标准普通话测试句，配上 18 个常见商务术语，在**所有特征都放开**的情况下，必须一字不改（`tests/core/accents.test.ts`）。这套测试找出了一个老问题：3 个字的术语只要和一个词有 2 个字相同就会替换，“销售数据”曾被改成“销售额据”。现在每个音节都必须读音相近才替换。
