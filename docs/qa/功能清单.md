# 0.9 功能清单与自动测试覆盖

本文件列出会议同传助手每个面向用户的功能，以及覆盖它的自动测试、测试在哪个系统上跑（按 2026-11-21 main 分支的代码和 `.github/workflows/ci.yml` 整理）。
0.9 发布条件：每个面向用户的功能，至少要有一个自动测试在用户实际使用的平台上走完真实操作流程。下表逐项标 已覆盖 / 部分覆盖 / 未覆盖，文末列出发布前要补的缺口。

**怎么读**
- 测试后括号里是 CI 跑它的系统：L = Linux（test 任务），M = macOS、W = Windows（desktop-os 任务），包 = 在刚打包好的安装包上再跑一遍（`scripts/test-packaged.sh`）。单元测试（`tests/`、`extension/tests/`）三个系统都跑；`*.os.test.ts` 和标了“真 Windows”的用例只在 M、W 上跑。desktop-os 只跑 app、buttons、devices、profile、restart、local-ai 六个 e2e；其余 e2e（glossary、offline-mt、room、extension、mobile、site）只在 Linux 跑。
- **已覆盖**：在用户用的平台上走完真实流程。电脑版 e2e 用假麦克风播测试音、用“演示”识别/翻译/语音（本机 AI 翻译那条除外），界面、音频引擎、录音文件都是真的；真实服务各占一行。插件测试用 Playwright 自带的 Chromium（与 Chrome 同内核），算插件平台。
- **部分覆盖**：只有单元测试；只在 Linux 跑而用户在 Mac/Windows；只在模拟设备、替身页面或桌面浏览器模拟的手机上跑；或只有“按钮全测”（`e2e/buttons.spec.ts › 按钮全测`：每个按钮点一次不报错、开关不弹回，不验证效果）。**未覆盖**：没有任何测试碰到。
