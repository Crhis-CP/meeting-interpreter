## A. 首次上手走查（从打开软件到开完第一场会）

实际的路径是：引导第 1 步“选方案”→ 第 2 步“填 Key”→ 第 3 步“虚拟声卡”→ 进入“会议同传”页 → 点“开始同传”。

### A1 选方案时只看得到名字和价格，看不出准不准、要下载多少、声音像不像人
- **位置**：`Onboarding.tsx:91-96`（卡片只渲染 `name` 和 `cost`）；`presets.ts:24`（免费方案的 `description` 写了“本机离线…第一次自动下载模型”，但引导里没显示出来）
- **现象**：免费方案的卡片上只有“免费方案 / 0 元 · 不用 Key”，而且默认就选着它（01-onboarding-step1.png）。卡片没告诉用户三件事：①第一次要下载约 **1.9 GB**（识别 617 MB + AI 翻译 1.1 GB + 离线翻译 138 MB，数字取自 12-free-settings-0-翻译服务.png 和 07-free-start-without-models.png）；②对方听到的是**系统自带的声音**；③和百炼相比准确度差多少。
- **为什么影响用户**：照着默认选了免费方案的人，第一场会会依次碰上：模型没下完开不了会、翻译被降级（见 A9）、对方听到机器人声。三件事都在打“准确第一”和“好上手”。
- **建议**：每张卡固定写三行：**准确度**（实测百分比或星级）、**声音**（自然人声 / 系统声音）、**需要什么**（“首次下载约 1.9 GB，下完才能开会” / “一个 Key，1 分钟拿到”）。默认选哪个，按“准确第一”重新定：至少要让用户明白“免费 = 先等下载”。

### A2 “演示模式”和真正的方案并排出现，选了它也没有任何提醒
- **位置**：`presets.ts:54-64`，引导和 设置 › 翻译服务 的方案网格里都有
- **现象**：演示模式是四个选项之一，选了它引导照样顺利走完。开会时会议页没有任何“当前是演示”的标识（24-demo-meeting-live.png 标题区什么都没写），译文还是“像模像样的固定台词”。
- **为什么影响用户**：新用户可能以为已经配好了，直接进真实会议，对方听到的是和自己说的话无关的固定句子。
- **建议**：把演示从方案里拿掉，改成引导底部一个小链接“先看看演示（不会真的翻译）”。演示进行时，会议页和字幕窗顶部一直挂着“演示模式：不是真实翻译”。

### A3 “填 Key”这一步的“测试”按钮测错了对象
- **位置**：`Onboarding.tsx:132-136`（`<TestPanel scope="llm">` 写死了只测大模型）
- **现象**：
  - 选百炼：只测“大模型（翻译 / 纪要）”，识别和语音合成都不测（05-onboarding-step2-test-result.png）。
  - 选 Azure：用户填了“语音服务 Key”和“翻译 Key”，点“测试”测的却是**智谱大模型**，报错“还没有保存大模型 Key：在‘翻译服务’里粘贴后点‘保存’”（70-onboarding-azure-test.png）。这个 Key 引导里根本没让填，“翻译服务”这个页面用户也还没见过。
- **为什么影响用户**：要么被一个莫名其妙的错误吓住，要么测试通过了但识别 / 合成其实不通，到第一场会才发现。
- **建议**：引导里的测试改成“用当前方案完整说一句”：中文测试句 → 识别 → 翻译 → 合成，**把声音播出来**，同时显示译文。Azure 这一步还要补上“区域”输入框（现在用的是默认的 eastasia）。

### A4 Azure 的 Key 标签写着“F0 免费层”，但方案说明里说 F0 做不了双向
- **位置**：`Onboarding.tsx:15-16`（标签“Azure 语音服务 Key（F0 免费层）”）和 `presets.ts:46`（“免费层 F0 同一时间只能识别一路，双向同传请用标准层 S0”）。后面这句说明在引导里看不到。
- **为什么影响用户**：用户按标签去开了 F0，开会时有一个方向的识别会失败，整场会只能翻一边。
- **建议**：标签改成“Azure 语音 Key（双向同传需标准层 S0）”，或者在引导里直接把这条限制写出来。

### A5 免费方案跳过了“填 Key”，可会后纪要和会后自动学习都需要大模型 Key，而且没 Key 时不报错
- **位置**：`presets.ts:27`（`needs: []`）；默认设置 `summary.autoAtEnd=true`、`interpretation.autoReview=true`；`session-manager.ts:506-512`（拿不到大模型就直接跳过，不提示）
- **现象**：免费用户开完第一场会，既没有纪要，也没有任何提示。只有翻到 设置 › 同传与语言 才会看到“自动学习要用大模型 [去填 Key]”（12-free-settings-2-同传与语言.png）。
- **为什么影响用户**：README 的卖点“会后自动生成双语纪要”在免费用户这里悄悄失效了。“会后自动学习”能提高下一场的准确度，也一起没了。
- **建议**：免费方案的第 2 步改成“可选：会后纪要和自动学习（免费的智谱 Key，1 分钟拿到）[跳过]”。如果跳过，这两个开关就显示为“未开启（需要 Key）”，不要显示“开着”却不干活。会议结束时如果因为缺 Key 没生成纪要，弹一条能点进去填 Key 的提示。

### A6 “虚拟声卡”这一步只有一个按钮：不解释、不验证、不提醒戴耳机
- **位置**：`Onboarding.tsx:140-162`、`DriverInstaller.tsx`
- **现象**：整页只有“一键安装虚拟麦克风”和“跳过，开始使用”（02-onboarding-step3-free.png）。没有一句话说明为什么要装（为了让对方在会议软件里听到译音）。已经装好时也只显示“会议软件的麦克风选 BlackHole 2ch”，没有让用户去会议软件里确认一下。没提醒**戴耳机**。没提醒**把会议软件的降噪调低**（这条在使用指南里有，引导里没有）。
- **为什么影响用户**：“对方什么都没听到”是第一场会最常见的失败，产品经理自己测试时也卡在这里。不戴耳机的话，外放的中文译音会被麦克风收进去，再被翻译一遍发给对方，翻译就乱了。
- **建议**：把这一步改成“对方能听到吗？”自检：①一句话讲清用途；②安装或检测虚拟声卡；③点“发测试音”，请用户看会议软件里的麦克风音量条有没有动（动了 / 没动，两个分支分别给下一步）；④勾选“我戴着耳机”；⑤提醒把会议软件的降噪调低或关掉。如果用户用的是网页版会议，在这一步直接引导去装 Chrome 插件，不用装虚拟声卡。

### A7 引导结束后，模型在后台下载，但几乎看不出下到哪了
- **位置**：`App.tsx:54-57, 86-92`（顶部那条只显示“下载模型 xx%”，而且是按单个文件算的）；`index.ts:284-290`（选好方案后三套模型同时开始下）
- **现象**：三套模型各下各的，顶部细条只显示当前那个文件的百分比，下完一个文件就跳回 0%。没有总进度，没有剩余时间，也看不出哪一套已经好了。
- **为什么影响用户**：用户不知道什么时候能开会，常常是会议马上开始了才发现还没下完。
- **建议**：在会议页顶部放一张“准备情况”卡：识别 ✓ / 翻译 62%（约 4 分钟）/ 声音 ✓，加上总进度和剩余时间。没全部准备好之前，“开始同传”按钮显示“还在准备（还要约 4 分钟）”。

### A8 下载明明失败了，点“开始同传”还说“正在下载”
- **位置**：`index.ts:798`（`requireLocalModels`）、`index.ts:753`（`requireOfflineMt`）
- **现象**：没网时点“开始同传”，红框写着“正在下载本机离线识别模型（约 617 MB），下载完成后即可开始同传”；与此同时，右下角的提示写的是“下载失败”（07-free-start-without-models.png）。
- **为什么影响用户**：用户会一直等一个永远下不完的下载。
- **建议**：分清两种状态。下载中：“正在下载（x%，剩约 N 分钟）”。下载失败：“下载失败（原因）[重试] [改用百炼，不用下载]”。

### A9 （最影响准确度）识别模型好了、AI 翻译模型还没好时，第一场会会悄悄用低质量的离线翻译顶上
- **位置**：`index.ts:323-327`，只弹一条 info 提示“这场先用离线翻译，下载好以后更准”，6 秒后消失。设置里点“测试 中→西”，结果写的是“离线翻译：离线翻译模型还没有下载”（13-free-settings-tests.png），说明本机 AI 翻译没准备好时确实会退回到离线翻译。
- **现象**：AI 翻译模型有 1.1 GB，是最大的一个，通常最后才下完。第一场会正好容易落在这个空档里。
- **为什么影响用户**：这直接违背“准确第一”。第一场会翻得差，用户就不会再来了。0.9 计划里“没下载完不开始正式同传”的方向和这一条一致。
- **建议**：不要悄悄降级。开始前先弹窗：“翻译模型还差 X MB（约 N 分钟）。现在开始，准确度会明显下降。[等下载完] [仍然开始]”。如果用户选了“仍然开始”，会议中给译文标上“草稿质量”，并且在会议页一直显示。

### A10 会议页的“开会前检查”只查虚拟麦克风
- **位置**：`Meeting.tsx:75-78`
- **现象**：检查列表里只有“没选虚拟麦克风”“没选会议声音”两项。下面这些都不查：Key 没填（百炼用户在引导里点了“稍后再填”，要等点“开始”才报错，73-dashscope-nokey-start.png）、模型没下完、纪要用的大模型 Key、有没有戴耳机、麦克风有没有声音 / 有没有授权。会议进行中顶部提示“未选择‘虚拟麦克风’输出设备：对方听不到译音”，但这条提示上没有“去设置”按钮（`Meeting.tsx:127-141` 只给 Mac 权限问题配了按钮）。
- **建议**：所有检查项放进同一张“准备情况”清单（和 A7 合并），每一项都带一键修复，点了直接跳到对应的设置页签。

### A11 “去设置”跳错了页签；报错里说的“服务设置”这个页面并不存在
- **位置**：`Meeting.tsx:76-77` 调用的是 `go('settings')`，设置页默认打开“翻译服务”页签（`Settings.tsx:34`）；`registry.ts:51/152`、`index.ts:369` 的报错写“请先在‘服务设置’里…”
- **现象**：点“对方听不到西语译音：没选虚拟麦克风 [去设置]”，打开的是“翻译服务”，可虚拟麦克风在“音频设备”页签里。报错让用户去“服务设置”，界面上只有“设置 › 翻译服务”（73-dashscope-nokey-start.png）。
- **建议**：`go('settings', 'devices')` 这样直接跳到具体页签，最好再定位到那个字段。报错文案统一写“设置 › 翻译服务”，报错框里放一个“去填写”按钮。

### A12 声音没法试听；免费方案默认就是系统自带语音
- **位置**：`Settings.tsx:122-139`（`VoiceSelect` 只有下拉框，没有试听）；`provider-test.ts`（测试时会合成语音，但不播放）
- **现象**：选音色时一个都听不到。点“测试 中→西”也只显示文字结果，没有声音。
- **为什么影响用户**：对方听到机器人声，是第一场会仅次于“不准”的流失原因（产品经理反馈的第 3 条）。现在用户在开会前没办法判断声音行不行。
- **建议**：每个音色旁边放一个“▶ 试听”，用外语示例句播放。引导最后一步播放一段完整样例：“你说的中文 → 对方会听到的西语”。

### A13 开会时切到别的页面再回来，会议页的实时记录就被清空了
- **位置**：`Meeting.tsx:18-33`（`useLiveSegments` 把句子存在页面组件自己的状态里，一切页组件就卸载，句子就没了）；`Room.tsx:16` 也是同样写法
- **现象**：开会时去“现场房间”页转了一下再回来，会议结束后会议页只剩回来之后的 2 句（24-demo-meeting-live.png 有 4 句 → 27-demo-meeting-ended.png 只剩 2 句）。“现场房间”页上也只显示切过去那一刻的 1 句（26-room-while-meeting.png）。
- **为什么影响用户**：会中去设置里调个音量，回来前面的字幕全没了，用户会以为记录丢了（其实“会议记录”里是完整的）。
- **建议**：把实时记录放到 App 这一层（或者放在主进程里）；或者回到会议页时，从主进程把当前会议的所有句子重新拉一遍。

### A14 会议页的“录屏”开关点了不变，而且关不掉　【670c073 已修】
- **位置**：`Meeting.tsx:176-177` → `index.ts:359`（`setRecording` 保存了设置，却没有通知界面）
- **现象（实测）**：点一下“录屏”，设置已经变成 true，开关还显示关；再点一次，设置还是 true。所以在会议页上永远关不掉录屏（21-demo-toggle-screen-rec.png）。之后开现场房间时弹出“录屏失败：未选择要录制的屏幕或窗口”（34-room-open.png）。
- **为什么影响用户**：用户以为没在录屏，其实每场会都在尝试录屏，有隐私问题。
- **状态**：`670c073` 已经改为“每次设置变化都通知所有窗口”。建议把“点开关 → 设置值和界面显示一致”加进回归测试。

### A15 “对方说话”这一路的开关是开着的，但状态永远是“待机”
- **位置**：`Meeting.tsx:248-253`
- **现象**：“会议声音来自”设成“不翻译会议声音”时，“对方说西语 → 我听中文”这张卡照样显示，开关是开的，状态一直写“待机”（24-demo-meeting-live.png）。
- **建议**：这种情况下卡片直接写“没有接入会议声音 [去设置]”，开关置灰。

### A16 第一场会最能提高准确度的两件事（术语、口音校准），上手流程里都没提
- **位置**：术语表默认的“我的术语表”是空的，“外贸常用术语（示例）”默认没启用（11-free-术语表.png、11-free-术语表-示例.png）；口音校准藏在 设置 › 同传与语言
- **为什么影响用户**：公司名、产品名、人名最容易翻错，引导里却从来没问过。
- **建议**：利用等模型下载的时间，在引导里加两件可以跳过的小事：“输入 3–5 个你们公司 / 产品 / 客户的名字”和“读 5 句话做口音校准（1 分钟）”。这和 0.9 计划里“下载期间做校准”是一致的。

### A17 Chrome 插件选“免费”时，如果电脑版没开，弹窗里不提示
- **位置**：`extension/src/popup.ts:83-87`
- **现象**：插件弹窗选“免费”、电脑版没在运行，等了 5 秒以上，弹窗里还是没有出现“未检测到桌面客户端”，“开始同传”照样能点（50-ext-popup-free.png、56-ext-popup-free-after.png）。只有插件的设置页会提示（53-ext-options-free.png）。
- **为什么影响用户**：0.9 计划推荐网页会议走插件，按这条路走的新用户第一次就会失败。
- **建议**：弹窗里“免费”下面固定显示一行“需要电脑版正在运行：✓ / ✗ [下载]”。没检测到电脑版时，把“开始同传”禁用，并说明原因。

### A18 安卓 App 默认用离线翻译（准确度最低的那个）
- **位置**：`mobile/src/app.ts:48`（`DEFAULTS.mt = 'offline'`）和 `:102`
- **现象**：安卓 App 本来就必须填百炼 Key（识别和语音都用百炼），翻译却默认选了“离线翻译（免费）”，而且开始前还得先下载 138 MB（61-phone-app-settings.png）。
- **为什么影响用户**：最不准的翻译成了默认，还平白多了一步下载。
- **建议**：默认改成 `qwen-mt`（百炼翻译）。离线翻译只作为“没网时的备用”。

## C. 看不懂的地方（行话、含糊的标签、点了没反应、走到死路）

### C1 行话太多
- **位置**：设置 › 翻译服务（12-free-settings-0-翻译服务.png、13-free-settings-tests.png）、音频设备
- **现象**：“大模型”“接口地址（OpenAI 兼容）”“纪要用模型”“业务空间主机”“qwen-audio-3.1-asr-flash-streaming（推荐，支持热词）”“Whisper small / base”“语音活动检测（Silero VAD）”“SenseVoice 小模型”“离线翻译（草稿）”“回声消除 / 降噪 / 自动增益”“虚拟扬声器 / 系统声音”“资源终结点”“F0 / S0”。测试项名字叫“大模型（翻译 / 纪要）”，可免费方案的翻译根本不用大模型。
- **建议**：普通视图只说人话，比如“会后纪要用的 AI：智谱（免费）”。模型名、接口地址一律收进“高级”。

### C2 报错直接把技术细节甩给用户，还有一处说错了模型
- **现象**：
  - “本机识别模型 silero-vad 的文件 silero_vad.onnx 下载失败（huggingface.co：net::ERR_PROXY_CONNECTION_FAILED；…）”（07-free-start-without-models.png）。
  - AI 翻译模型下载失败时，也说成“本机识别模型 hy-mt2-1.8b 的文件 Hy-MT2-1.8B-Q4_K_M.gguf…”：两种模型共用了一句文案，把翻译模型说成了识别模型（`model-manager.ts:247`）。
  - 离线翻译下载失败显示“Error invoking remote method 'mi:fetch-bytes': Error: net::ERR_…”。
  - 公网链接失败时只有一行“net::ERR_PROXY_CONNECTION_FAILED”（35-room-public.png）。
- **建议**：用用户听得懂的话写原因，并分好类（网络不通 / 磁盘空间不够 / 被防火墙拦了），配一个“重试”按钮。技术细节放进“复制诊断信息”。

### C3 标签和实际行为对不上
- 对方说英语时，按钮仍然写“测试 中→西 / 测试 西→中”（`Settings.tsx:530`，74-settings-dashscope-english.png）；托盘菜单“翻译我的发言（中→西）”也一样。
- 按钮写“导入 CSV / Excel”，但文件选择框只认 .csv / .txt / .tsv（`index.ts:301`），.xlsx 文件根本选不到。
- 快捷键叫“按键说话”，实际是按一下切换（B11）。
- “默认录制”其实就是会议页上那两个开关（B6）。
- 同一个设置页里，“口音”（对方的口音）和“口音校准”（我自己的口音）挨在一起，很容易混。
- 术语表“启用”有两层：整张表一个开关，每一行一个勾。示例表整张关着，每行却都勾着（11-free-术语表-示例.png）。“常被听成”列的占位符是“；”，看起来像已经填了一个分号。

- 模型列表用 ✅ / ⬜ 字符表示状态，⬜ 看起来像能勾的复选框（12-free-settings-0-翻译服务.png）。

### C4 点了没有反馈
- 设备页的“试音”“自动识别虚拟声卡”“刷新”点了没有任何反馈。试音的声音是送进虚拟麦克风的，用户自己听不到，也没人告诉他去哪儿看效果。（`670c073` 给“试音”加了按下确认；“自动识别”找不到设备时仍然不说。）

- 免费方案会后纪要因为缺 Key 没生成，也不说一声（A5）。
