# 隐私政策（会议同传助手 桌面客户端与 Chrome 插件）

最后更新：2026-11-20

会议同传助手是免费开源软件。**开发者没有任何服务器，不收集、不接收、不出售你的任何数据。**

## 处理哪些数据

- **会议声音和文字**：同传进行时，你的麦克风声音和会议里对方的声音，会被发送到**你自己选择并填写 Key 的服务**（例如阿里云百炼、微软 Azure、智谱、DeepL），用来识别、翻译和合成语音。选择免费版 / 本机离线识别时，声音只在你的电脑上处理。
- **服务 Key**：只保存在你的电脑上（桌面版用系统加密存储；插件保存在浏览器的扩展存储里），只发送给对应的服务。
- **术语表、会议记录、纪要**：只保存在你的电脑上（桌面版的记录文件夹；插件的浏览器存储）。你可以随时删除。

## 不做什么

- 不收集浏览历史、网页内容、位置或任何个人身份信息。
- 插件只在会议网站（Teams、Google Meet、飞书、腾讯会议、Zoom、Webex）上运行，且只在你点“开始同传”后才处理声音。
- 不做统计分析，不投放广告，不把数据给任何第三方（你自己选择的翻译服务除外）。

## 第三方服务

你选择的服务会按它们自己的隐私政策处理收到的声音和文字，请查看对应服务的条款。
