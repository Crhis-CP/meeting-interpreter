# 翻译准确度与速度实测

测试日期：2026-11-20。48 句常见商务会议用语，四个方向各 12 句：中→西、西→中（含阿根廷口语）、中→英、英→中。
句子在 [`scripts/dev/bench-cases.json`](../scripts/dev/bench-cases.json)，大模型那一组可以用 [`scripts/dev/bench-zhipu.mts`](../scripts/dev/bench-zhipu.mts) 自己重跑。

- **离线翻译**：本软件内置的免费离线翻译（Mozilla 模型），在普通电脑的浏览器内核里运行。
- **本机 AI 翻译**：腾讯开源的翻译模型 Hy-MT2-1.8B（Apache-2.0，4 位量化，1.1 GB），用 llama.cpp 在电脑上运行。测试机是 4 核服务器 CPU、没有显卡（苹果 M 系列芯片会更快）。
- **大模型**：智谱 GLM-4.7-Flash（免费），走本软件自己的翻译代码，一句一句地发。
- **评分**：逐句人工检查。✓ 意思完全正确；△ 能看懂，但有小错或不通顺；✗ 意思错了。

## 结果

| | 离线翻译（免费） | **本机 AI 翻译（免费）** | 智谱大模型（免费 Key） |
|---|---|---|---|
| 需要 | 下载 140 MB | 下载 1.1 GB | 联网 + Key |
| 每句耗时（中位数） | **0.06 秒** | 约 1 秒 | 0.9 秒 |
| 最慢一句 | 0.1 秒 | 2.3 秒 | 2.9 秒 |
| ✓ 完全正确 | 32 / 48（67%） | **44 / 48（92%）** | 44 / 48（92%） |
| ✓ + △ 能看懂 | 44 / 48（92%） | **48 / 48（100%）** | 48 / 48（100%） |
| ✗ 意思错 | 4 句 | 0 句 | 0 句 |

分方向（✓ / △ / ✗）：

| 方向 | 离线翻译 | 本机 AI 翻译 | 智谱大模型 |
|---|---|---|---|
| 中→西 | 8 / 3 / 1 | 11 / 1 / 0 | 11 / 1 / 0 |
| 西→中 | 7 / 3 / 2 | 10 / 2 / 0 | 10 / 2 / 0 |
| 中→英 | 8 / 3 / 1 | 12 / 0 / 0 | 12 / 0 / 0 |
| 英→中 | 9 / 3 / 0 | 11 / 1 / 0 | 11 / 1 / 0 |

本机 AI 翻译的 4 个小问题：“de adelantado”应为“por adelantado”；“他们什么时候能交付”应为“你们”；“Dale”翻成“戴尔”（软件翻译前会先把它换成标准西语，换完就对了）；“样本”应为“样品”。

### 更大的本机模型：Hy-MT2-7B（可选）

同一套 48 句，换成同系列的 7B 模型（4 位量化，4.6 GB）：

| | Hy-MT2-1.8B（默认） | Hy-MT2-7B |
|---|---|---|
| 需要 | 下载 1.1 GB | 下载 4.6 GB，内存 8 GB 以上 |
| 每句耗时（中位数，4 核 CPU） | 约 1 秒 | 4.9 秒 |
| 最慢一句（4 核 CPU） | 2.3 秒 | 16.2 秒 |
| ✓ 完全正确 | 44 / 48（92%） | **46 / 48（96%）** |
| ✗ 意思错 | 0 句 | 0 句 |

7B 把 1.8B 的“de adelantado”“他们什么时候”“样本”三处都翻对了，剩下两个小问题：“Dale”翻成“戴尔”（软件会先换成标准西语）；“llegaron cajas rotas”翻成“箱子都是破损的”（原意是“有些箱子破了”）。
在普通 CPU 上 7B 太慢，跟不上同传，所以软件只在苹果 M 系列芯片的 Mac 上提供这个选项（用显卡加速；这台测试机没有 Mac，Mac 上的速度没有实测）。

为什么不“训练”离线翻译：重新训练翻译模型需要大量双语语料和显卡跑很多小时，不适合在每个人的电脑上做。换成更新、更好的开源翻译模型，再配合你的术语表和纠错字典，效果更好也更省事。

大模型的速度和当时的网络、服务器繁忙程度有关：这次每句约 1 秒；之前测试时遇到过限流，单句要等好几秒。

## 离线翻译典型错误

- “这个方案你们觉得怎么样？” → “¿Qué te parece este *programa*?”（“方案”应为 propuesta / plan）
- “质量问题我们负责免费更换。” → 意思乱了
- “Necesitamos la factura antes de que llegue la mercadería…” → “我们需要……之前*支付账单*”（应为“拿到发票”）
- “¿El producto tiene certificación para vender en Argentina?” → 漏掉了“认证”
- “…el flete hasta Buenos Aires” → “*飞往*布宜诺斯艾利斯的运费”

这些错误在两段式翻译里会被大模型的正式译文替换掉；只用离线翻译时，可以把常用词加进术语表（例如 方案 → propuesta、flete → 运费），之后都会按你的写法翻。

## 阿根廷口语

离线模型本身能看懂 vos 的变位（tenés、querés、podés），但会把几个常用口头语翻错，例如 Che → “切”、Dale → “戴尔”、Bárbaro → “巴巴鲁斯”、Nos parece bien → “我们很好”。
现在离线翻译前会先把这些说法换成标准西语（Che 去掉；Dale → De acuerdo；Listo → Bien；Bárbaro → Genial；Ojo → Atención；re caro → muy caro；¿viste? 去掉；me/nos parece bien → estoy/estamos de acuerdo；laburo → trabajo；me pasás → me das），这几句就都翻对了。只在这些词单独作口头语时才换，“Dale el catálogo a Juan”“El pedido está listo”这类正常用法不动。

## 0.9 提速（2026-11-21）

同一台 4 核服务器 CPU、同样 2 个线程（软件在 4 核电脑上的默认值），48 句两个方向交替翻译，走软件自己的翻译代码（[`scripts/dev/latency-bench.mts`](../scripts/dev/latency-bench.mts) 可以重跑）：

| | 改之前 | 改之后 |
|---|---|---|
| 每句耗时（中位数） | 2.66 秒 | **1.23 秒** |
| 90% 的句子在 | 3.77 秒内 | **1.88 秒内** |
| 最慢一句 | 5.2 秒 | 3.4 秒 |
| 第一句 | 3.35 秒 | 1.80 秒 |
| ✓ 完全正确 | 45 / 48 | **46 / 48** |
| ✗ 意思错 | 0 | 0 |

改了什么：
- 去掉了翻译库默认加在每句前面的英文“系统提示”（约 55 个词元，模型训练时并没有它），改用 Hy-MT 自己的对话格式。
- 两个方向各用一条通道，各自的“指令”部分算一次就留着，新的一句只算它自己的字；两个方向可以同时翻。
- 逐句人工复核：48 句里 22 句措辞有变化，没有一句变差；“samples”从“样本”变成了“样品”，“两年期的保修期”变成了“两年保修期”。剩下的两个小问题和以前一样：“de adelantado”应为“por adelantado”，“你们”译成了“他们”。

## 结论

- **本机 AI 翻译**（免费方案的默认翻译）：准确率和云端大模型一样，不联网、不用 Key、会议内容不出电脑，每句约 1 秒。
- **离线翻译**最快（说完就出），只作为“先出的草稿”。AI 模型还没下载好时，不会用它凑合开会：会议页会提示下载进度，下载完再开始（等不及可以换云端方案）。
- 软件会先显示离线草稿（灰色斜体），AI 或大模型的译文到了再替换；超过 8 秒没回或出错，就直接用离线译文。
- 术语表对三种翻译都生效：本机 AI 翻译会把你的术语当作“参考译法”。
